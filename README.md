# 📅 스케줄 (Schedule)

> 계획을 자주 까먹는 사람을 위해 만든, 심플한 iOS 달력 일정 관리 앱입니다.

<br>

## 💡 기획 배경
- **"계획을 자주 까먹는 사람들을 위한 솔루션"**
- 시중에 나온 달력 앱들은 기능이 너무 복잡하여 정작 중요한 계획을 놓치기 일쑤였습니다. 
- 내가 필요한 기능(등록, 확인, 체크, 삭제)만 담아 직관적으로 일정을 관리하기 위해 개발했습니다.

<br>

## ✨ 주요 기능 (Key Features)
- **달력 기반 계획 저장**: 원하는 날짜를 선택하고 계획을 입력한 뒤 저장하면 해당 날짜에 데이터가 안전하게 기록됩니다.
- **상세 계획 조회**: 달력에서 특정 날짜를 터치하면 그날 해야 할 계획들을 한눈에 확인할 수 있습니다.
- **할 일 체크 (완료 처리)**: 완료한 계획은 간편하게 체크하여 달성 여부를 표시합니다.
- **유연한 계획 삭제**: 계획이 취소되거나 더 이상 필요 없어지면 언제든지 삭제할 수 있습니다.
